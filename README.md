# PhdQualCoach — public demo

A self-contained, in-browser demo of **PhdQualCoach** (a coach for the NYCU PhD
qualifying exam, AI + Algorithms). Open `index.html` (or the GitHub Pages URL) —
retrieval, citations, and the WARN grounding gate all run client-side, no server.

This demo ships only a small **CC0-1.0** seed corpus. The retrieval/coach engine,
the eval harness, and any real exam materials live in a separate private
repository and are **not** part of this demo.
