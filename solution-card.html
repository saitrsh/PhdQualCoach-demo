題目　Consider A* GRAPH search with an admissible heuristic h. (a) Give the form of the evaluation function f(n). (b) State the condition on h that guarantees A* returns an optimal solution under graph search. (c) Explain, with a small example, why admissibility ALONE is not sufficient once repeated states are eliminated.
Verified: PARTIAL Confidence 0.95
⚠️ A* with an admissible heuristic is optimal for TREE search. For GRAPH search (closed-set / repeated-state elimination) admissibility alone is NOT enough — you also need a CONSISTENT (monotone) heuristic, or you must allow node reopening. Assumes finite, non-negative step costs.
Tree search or graph search?Heuristic admissible?Heuristic consistent (monotone)?Repeated-state checking / node reopening?Non-negative step costs?

⚠️ 常見錯誤 · 🤖 LLM 每題生成

  • Writing f(n)=g(n)+h(n) but omitting that g(n) is the cost from the start node to n.
  • Claiming that admissibility alone guarantees optimality in graph search, forgetting the need for consistency (monotonicity).
  • Providing an example that does not involve repeated‑state elimination, or using a heuristic that is actually consistent, thus not illustrating the failure.

🎯 應試策略

  • State the evaluation function explicitly as f(n)=g(n)+h(n) and define g(n) and h(n).
  • Specify the required condition: h must be consistent (for every edge (n,m), h(n) ≤ c(n,m)+h(m)), which implies admissibility and guarantees optimality with closed‑list graph search.
  • Present a tiny graph (e.g., S→A→G and S→B→A→G) where h is admissible but not consistent, show that A* expands A via the cheaper S→A path, closes it, then later discovers a cheaper path to A via B, but cannot reopen A, leading to a sub‑optimal solution.

🔀 其他解法

  • Use a consistent heuristic instead of merely admissible; consistency is sufficient for optimality in graph search.
  • Allow node re‑expansion (i.e., do not prune repeated states) – with an admissible heuristic this also yields optimal solutions.
