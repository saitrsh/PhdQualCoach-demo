題目　Consider A* GRAPH search with an admissible heuristic h. (a) Give the form of the evaluation function f(n). (b) State the condition on h that guarantees A* returns an optimal solution under graph search. (c) Explain, with a small example, why admissibility ALONE is not sufficient once repeated states are eliminated.
Verified: PARTIAL Confidence 0.95
⚠️ A* with an admissible heuristic is optimal for TREE search. For GRAPH search (closed-set / repeated-state elimination) admissibility alone is NOT enough — you also need a CONSISTENT (monotone) heuristic, or you must allow node reopening. Assumes finite, non-negative step costs.
Tree search or graph search?Heuristic admissible?Heuristic consistent (monotone)?Repeated-state checking / node reopening?Non-negative step costs?

⚠️ 常見錯誤 · 🤖 LLM 每題生成

  • Writing f(n)=g(n)+h(n) but omitting that g(n) is the cost from the start node to n.
  • Claiming that admissibility alone guarantees optimality in graph search, ignoring the need for consistency (monotonicity).
  • Providing an example that does not involve repeated‑state elimination, so it does not illustrate why admissibility alone fails.

🎯 應試策略

  • State the evaluation function explicitly as f(n)=g(n)+h(n).
  • Specify the required condition: h must be consistent, i.e., for every edge (n,m), h(n) ≤ c(n,m)+h(m). Mention that consistency implies admissibility and ensures optimality with graph search.
  • Give a tiny graph (e.g., start → A → Goal and start → B → Goal) where a non‑consistent admissible heuristic causes the A* frontier to discard the optimal path after expanding a duplicate state.

🔀 其他解法

  • Use A* in tree‑search mode (no closed list) where admissibility alone is sufficient.
  • Apply path‑max or enforce consistency on the heuristic to recover optimality in graph search.
